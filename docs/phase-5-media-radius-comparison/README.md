# Temporary shared-ticket media radius comparison

These review-only PNGs compare the existing shared layered ticket with temporary media corner radii of 2px, 4px, and 6px. Rows are labeled in that order. The outer card (8px) and light-grey panel (4px) retain their existing radii.

Captures use French Pilates content at 100% browser zoom, device scale factor 1, Chromium 154.0.8037.57, locale en-GB, Europe/Paris timezone, light color scheme, and reduced motion set to no-preference. Viewports are 1440x900 (desktop) and 1194x834 (tablet landscape). Each variant was applied as a temporary browser stylesheet override; no application source or baseline reference was changed. Ticket dimensions remained 1142x393px on desktop and 770x310px on tablet.

These are visual review artifacts, not approved regression references. No radius change is made by this comparison.
