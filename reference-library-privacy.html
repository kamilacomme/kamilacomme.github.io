Kamila Comme Reference Library

A proposed personal, read-only design-reference tool operated by Kamila Ayubova (Kamila Comme).

Status: pre-launch. Pinterest API access has not been approved or activated. This page describes the proposed application and its intended data handling. It does not claim Pinterest endorsement or permission for external AI processing.

Privacy policy

Last updated: 25 October 2026.

Operator and contact

Kamila Ayubova, working under the name Kamila Comme. Questions about this application or personal data: comme.kamila@gmail.com.

Purpose and intended access

The application is intended solely for the operator's own design-reference workflow: viewing her Pinterest boards and saved Pins, reviewing visual references, and identifying composition, typography, colour and stylistic patterns. It is not a public service and does not accept other users.

Requested API access will be limited to reading the authenticated operator's own public boards and Pins. The intended data includes board and Pin identifiers, titles, descriptions, source links, and media information returned by the permitted API endpoints. No advertising, publishing, editing, deletion, private messaging or secret-board access is proposed.

Current collection and website hosting

The application is not yet connected to Pinterest and currently collects no Pinterest account data. This standalone information page has no analytics scripts, forms, cookies set by this page, or advertising. It is hosted on GitHub Pages. GitHub states that it logs visitors' IP addresses for security purposes; see GitHub's privacy statement. The portfolio homepage has its own privacy information; this policy concerns this application and this standalone page.

Proposed processing and retention

If access is approved, Pinterest data will be requested only as needed for the authorised personal workflow. The application will not maintain a persistent archive of API-derived Pins, images, board data or account information. Credentials must remain private and outside public source code and public web pages. The credential-storage and processing implementation will be documented here before activation.

External AI processing

The desired workflow includes visual assistance from an external AI service, such as OpenAI's ChatGPT. No Pinterest API data is currently sent to any AI provider by this application. External AI processing will not be enabled unless it is permitted by Pinterest and the processing, provider, retention and applicable transfer arrangements have been established and disclosed here before activation. An API-access approval alone will not be presented as permission for an otherwise restricted use.

The application will not use Pinterest data to train, fine-tune or develop AI models. It will not sell API data, make API data public, or use it for advertising or profiling other people.

Control and requests

The operator can stop using the application and revoke any future Pinterest authorisation through Pinterest's available controls. For access, correction, deletion or privacy questions concerning data actually processed by the application, contact the operator above. Where applicable, individuals may also contact their competent data-protection authority.

Changes before launch

This policy will be updated before any material change or activation of processing. The final implementation must comply with Pinterest's developer requirements and applicable data-protection law.
